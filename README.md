# RM330 BLE Joystick

Приложение для пульта DJI RC (RM330), превращающее его физические стики и
кнопки в обычный HID-геймпад для PC — для авиасимуляторов/эмуляторов,
без доработок на стороне компьютера.

Пакет: `dev.g992.rcviewer`.

## Режимы

- **USB-джойстик (HID)** — создаёт HID-гаджет прямо в живом USB-гаджете пульта
  (`/config/usb_gadget/g1/functions/`), поверх штатных MTP/ADB-интерфейсов,
  VID/PID не меняются. Требует root-доступ на пульте (см. ограничение ниже).
- **BLE-джойстик** — HID-over-GATT (服务 0x1812) через публичный Android BLE API,
  без root. Имя адаптера — "DJI RC".

Оси сопоставлены под нумерацию Gamepad API (как видит Windows/Chrome):
левый стик X(0)/Y(1), правый Z(2)/Rx(3); C/N/S — кнопки 5/6/7, флаг-переключатели
снятые со стиков и кнопок читаются из DUML-телеметрии `dji_link` (TCP 40007/40009).

## Известные ограничения

- **USB-HID ломает штатные Windows-инструменты DJI**, пока включён: гаджет
  занимает interface 0, сдвигая номера MTP/ADB/обоих bulk-интерфейсов DJI —
  Windows не распознаёт их по старым `MI_NN` ID. Выключать перед работой с
  DJI Assistant/MTP/ADB по USB, причём именно тумблером в приложении
  (force-stop/убийство процесса пропускает корректное отключение гаджета).
- **BLE: переподключение после перезапуска не работает** — баг на стороне
  Windows (после remove/re-pair подключается). Доказано снифом HCI: пульт
  рекламируется и принимает соединения корректно, Windows просто не пытается
  подключиться повторно. Нужно каждый раз удалять и заново добавлять
  Bluetooth-устройство "DJI RC" в Windows.
- C1/C2 и диск (дайлы) недоступны через порт 40007 — закрытый канал у DJI.

## Сборка

```
cd rc_control_viewer
gradle assembleDebug
adb -s <ip>:5555 install -r app/build/outputs/apk/debug/app-debug.apk
```

Тот же toolchain, что и в [RM330 Launcher](https://github.com/g992/rm330-launcher).

Подробности реверса USB-гаджета/конфигурации, протокола DUML и история находок —
в приватном репозитории исследования RM330 (не публикуется).
